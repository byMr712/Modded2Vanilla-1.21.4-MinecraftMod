# Modded2Vanilla (Minecraft 1.21.4 Fabric)

![Java 21](https://img.shields.io/badge/Java-21-blue.svg)
![Minecraft](https://img.shields.io/badge/Minecraft-1.21.4-blue.svg)
![Fabric](https://img.shields.io/badge/Loader-Fabric-blue.svg)
![License](https://img.shields.io/badge/License-Apache_2.0-blue.svg)

Клиентский мод для **Minecraft 1.21.4 (Fabric)**, который обеспечивает совместимость клиентских контентных сборок с ванильными и сторонними мультиплеер-серверами.

---

## О моде

**Modded2Vanilla** — специализированный клиентский слой изоляции и совместимости. Мод позволяет играть с любыми контентными модами (на блоки, мобов, оружие, броню, еду, декорации и кастомные сущности) в одиночной игре и беспрепятственно подключаться к внешним серверам (Vanilla, Paper, Purpur, Spigot, Realms и через ViaFabricPlus) без необходимости отключать моды или менять профили лаунчера.

---

## Проблема, которую решает мод

При установке контентных модов на клиент они расширяют метаданные сущностей (`DataTracker`) и регистрируют кастомные элементы. При входе с такой сборкой на обычный сервер (Vanilla, Paper, Spigot и т.д.) или на сервер другой версии через **ViaFabricPlus**, происходят сетевые сбои:
- Смещаются индексы метаданных сущностей (`DataTracker`), вызывая исключения `Invalid entity data item type` и `ArrayIndexOutOfBoundsException` при появлении мобов или игроков.
- Возникают сбои при обработке сетевых пакетов звуков, частиц и экранов.
- Нарушается порядок инициализации реестров при ранней загрузке модов.

---

## Возможности

- **Интеллектуальная защита метаданных (`DataTracker`)**:
  - Автоматически проверяет соответствие типов данных сущностей между сервером и клиентом.
  - Корректирует смещения индексов при подключении к ванильным серверам.
  - Предотвращает вылеты и разрывы соединения при получении несовместимых сетевых пакетов сущностей.
- **Безопасная обработка сетевых пакетов**:
  - Фильтрует некорректные или неизвестные идентификаторы звуков и частиц от серверов, предотвращая разрыв соединения (`Internal Exception`).
- **Изоляция ранней регистрации реестров**:
  - Защищает ванильные реестры от загрязнения во время начальной загрузки игры.
- **Бесшовная поддержка ViaFabricPlus**:
  - Обеспечивает стабильную работу трансляторов сетевых протоколов при подключении к серверам старых версий (от 1.8 до 1.21.x).

---

## Автоматическое распределение режимов

Мод не требует ручной настройки и адаптирует поведение автоматически:

| Режим игры | Поведение |
|---|---|
| Одиночная игра (Singleplayer) | Изоляция отключена: весь контент, блоки, мобы, крафты и предметы из модов работают в полном объёме |
| Ванильный сервер (Vanilla / Paper / Purpur / Spigot / Realms) | Изоляция активна: подключение без конфликтов реестров, смещений DataTracker и сетевых вылетов |
| Сервер с установленными модами (Fabric) | Изоляция пассивна: моды, присутствующие на сервере, синхронизируются штатно |
| Подключение через ViaFabricPlus (любые версии) | Изоляция активна: трансляторы пакетов работают стабильно с чистыми метаданными |

## Установка

1. Скачайте последнюю версию со страницы [GitHub Releases](https://github.com/byMr712/Modded2Vanilla-1.21.4-MinecraftMod/releases).
2. Требуется [Fabric API](https://modrinth.com/mod/fabric-api).
3. Поместите `.jar` файл в папку `mods`.
4. Запустите игру.

---

## Сборка

1. Требуется Java 21 и Fabric Loader для Minecraft 1.21.4.
2. Для сборки выполните:
   ```bash
   ./gradlew build
   ```
3. Собранный файл находится в `build/libs/Modded2Vanilla-1.21.4-byMr712.jar`.
